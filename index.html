المقدمة

تعد لغة CSS (Cascading Style Sheets) أحد الأعمدة الأساسية لبناء وتطوير المواقع الإلكترونية. تُستخدم هذه اللغة لتحديد مظهر وتنسيق صفحات الويب المكتوبة بلغة HTML، حيث تمنح المطورين القدرة على التحكم في الألوان، الخطوط، الأبعاد، وتوزيع العناصر بشكل مرن وجذاب.

أهمية ومميزات لغة CSS

تكمن الأهمية الكبرى للغة CSS في فصل المحتوى عن التصميم. هذا الفصل يتيح للمبرمجين تعديل مظهر الموقع بالكامل من خلال تعديل ملف واحد فقط، مما يوفر الكثير من الوقت والجهد.

طرق كتابة أكواد CSS داخل صفحة الويب

النوع (Type) الوصف والاستخدام
Inline CSS تُكتب الأكواد مباشرة داخل وسم الـ HTML وتؤثر على عنصر واحد فقط.
Internal CSS تُكتب الأكواد داخل وسم style في رأس الصفحة وتؤثر على الصفحة الحالية.
External CSS تُكتب في ملف خارجي منفصل بصيغة .css وتُربط بجميع صفحات الموقع.
